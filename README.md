# WhisperApp Releases

Auto-Update-Feed für [WhisperApp](https://github.com/Swifty-Chris/whisper-releases) — eine native macOS Menu-Bar-Dictation-App.

Die `appcast.xml` wird von Sparkle (dem macOS Auto-Update-Framework) gelesen. Neue Versionen werden als GitHub Release Assets in diesem Repo veröffentlicht.

**Source Code** befindet sich in einem separaten privaten Repository.
